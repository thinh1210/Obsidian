# Hướng dẫn nạp code (Flashing) cho board XIAO nRF52840 Sense

## Vấn đề nạp file UF2 mặc định trên Zephyr v4
Khi build project bằng Zephyr v4.4.1 cho board `xiao_ble/nrf52840/sense`, file `.uf2` mặc định được tạo ra có Family ID `0xADA52840`. 
Bootloader của board XIAO BLE sẽ **từ chối nạp** file này (khi copy vào ổ đĩa ảo, nó chỉ hiển thị như file thường và board không tự reset).

## Cách giải quyết (Thay đổi cách nạp)
Để nạp thành công, bạn cần convert thủ công file `zephyr.bin` sang định dạng UF2 bằng script Python đi kèm của Zephyr, kèm theo tham số Family ID dành riêng cho cấu trúc của board XIAO BLE là `-f 0xD663823C`.

### Family ID là gì và tại sao phải đổi?
Định dạng file **UF2** (USB Flashing Format) được tạo ra để giúp việc nạp code dễ dàng như việc copy một file vào USB. Tuy nhiên, để tránh rủi ro người dùng copy nhầm firmware của board mạch này sang board mạch khác (có thể gây hỏng hóc hoặc brick thiết bị), UF2 thiết kế ra một cơ chế an toàn gọi là **Family ID**.

- **Family ID** (Mã định danh kiến trúc) là một chuỗi số hexa được nhúng trực tiếp vào file `.uf2` để "khai báo" rằng file firmware này được biên dịch riêng cho loại chip hoặc board mạch nào.
- Trên board XIAO BLE của bạn, chương trình **Bootloader** (chạy ngầm khi bạn mở ổ đĩa ảo) đã được nhà sản xuất thiết lập sẵn để chỉ nhận diện một vài Family ID cụ thể. Khi bạn copy file UF2 vào, Bootloader sẽ đọc đối chiếu:
  - Nếu **khớp**: Bootloader tiến hành flash code vào bộ nhớ và tự động reset board để chạy.
  - Nếu **không khớp**: Bootloader phớt lờ file đó (bạn chỉ thấy file nằm trong ổ đĩa như file dữ liệu thường) và board không thực thi lệnh.

**Nguyên nhân gây ra lỗi "không chịu nhận code" trên Zephyr:**
- Mã `0xADA52840`: Là Family ID tiêu chuẩn do hãng Adafruit khởi xướng cho dòng chip nRF52840 nói chung. Hệ thống build của Zephyr đang mặc định dùng mã này khi tự động xuất file UF2 cho mọi kiến trúc nRF52840.
- Mã `0xD663823C`: Hãng **Seeed Studio** (sản xuất board XIAO BLE) đã tùy chỉnh lại Bootloader và họ gán một Family ID định danh riêng cho board của họ. 
- Vì Zephyr (hiện tại chưa cấu hình chuẩn cho riêng board này ở bản 4.4.1) xuất ra mã `0xADA...` nên Bootloader Seeed không nhận. Giải pháp của chúng ta là lấy lõi firmware thô (`zephyr.bin`) và sử dụng tool `uf2conv.py` để "đóng gói" lại nó thành UF2 với đúng cái nhãn `0xD663823C` mà Seeed XIAO yêu cầu.

### Các bước thực hiện:

1. Build project bình thường để hệ thống tạo ra file `zephyr.bin` (nằm trong thư mục `build/zephyr/`):
   ```bash
   west build -p always -b xiao_ble/nrf52840/sense <thư_mục_project>
   ```

2. Chạy lệnh sau (từ thư mục gốc của zephyrproject) để convert `zephyr.bin` thành `flash.uf2` với đúng Family ID:
   ```bash
   python3 zephyr/scripts/build/uf2conv.py build/zephyr/zephyr.bin -c -f 0xD663823C -o flash.uf2
   ```

3. Đưa board về chế độ Bootloader: Rút cáp USB ra cắm lại, sau đó nhấn đúp nút reset (hoặc chạm chập 2 pad RST) **cực nhanh 2 lần liên tiếp (double-tap)**. Một ổ đĩa ảo sẽ xuất hiện trên máy tính.

4. Copy file `flash.uf2` vừa được tạo ra vào ổ đĩa ảo. Board sẽ tự động tiếp nhận, nạp code, reset và chạy ứng dụng bình thường.
