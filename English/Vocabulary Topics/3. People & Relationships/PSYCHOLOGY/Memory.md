# Memory
*noun*
> /ˈmem.ə.ri/

---
**Level:** A2 | **Ngữ cảnh:** Daily | **Chủ đề:** PSYCHOLOGY

## 📌 Ý nghĩa (Meaning)
- **EN:** The faculty by which the mind stores and remembers information.
- **VN:** Trí nhớ, kỉ niệm

## 🧠 Mẹo nhớ (Mnemonics)
💡 Memory = Mê mẩn ký ức.

## 🧩 Cụm từ thường đi kèm (Collocations)
- `good memory`: trí nhớ tốt

## 🎬 Ví dụ thực tế (Real-world Examples)
1. 💬 *Daily:* I have a bad memory.
   *-> Tôi có trí nhớ tồi.*
2. 💼 *Work/Academic:* The software requires more memory.
   *-> Phần mềm cần nhiều bộ nhớ hơn.*
3. 🎬 *Media/Movie:* Thanks for the memories.
   *-> Cảm ơn vì những kỉ niệm.*

## 🕸️ Mạng lưới từ (Word Network)
**Word Family:**
- memorize (verb)

**Synonyms:** recall, remembrance
**Antonyms:** forgetfulness
