# Server
*n.*
> /ˈsɜːrvər/

---
**Level:** B2 | **Ngữ cảnh:** Work/Daily | **Chủ đề:** INFORMATION TECHNOLOGY - TECHNOLOGY

## 📌 Ý nghĩa (Meaning)
- **[EN]:** A computer or computer program which manages access to a centralized resource or service in a network.
- **[VN]:** Máy chủ.

## 🧠 Mẹo nhớ (Mnemonics)
💡 Serve (phục vụ) + -er (người/máy) -> Máy phục vụ dữ liệu cho máy khác.

## 🧩 Cụm từ thường đi kèm (Collocations)
- `server crash`: Sập máy chủ
- `cloud server`: Máy chủ đám mây
- `server downtime`: Thời gian máy chủ ngừng hoạt động
- `host a server`: Vận hành/lưu trữ một máy chủ
- `dedicated server`: Máy chủ chuyên dụng (riêng)

## 🎬 Ví dụ thực tế (Real-world Examples)
1. 💬 *Daily:* The game is lagging because the server is overloaded.
   *-> Trò chơi bị giật lag vì máy chủ đang quá tải.*
2. 💼 *Work/Academic:* We are migrating our database to a new, more secure server.
   *-> Chúng tôi đang di chuyển cơ sở dữ liệu sang một máy chủ mới an toàn hơn.*
3. 🎬 *Media/Movie:* The hackers managed to breach the main server room.
   *-> Những kẻ tấn công đã xâm nhập thành công vào phòng máy chủ chính.*
4. 📰 *News:* The company's servers went down for six hours, disrupting service worldwide.
   *-> Máy chủ của công ty ngừng hoạt động suốt sáu tiếng, làm gián đoạn dịch vụ trên toàn thế giới.*
5. 🎓 *Academic:* The tutorial explains how to set up a basic web server using Node.js.
   *-> Bài hướng dẫn giải thích cách thiết lập một máy chủ web cơ bản bằng Node.js.*

## 🕸️ Mạng lưới từ (Word Network)
**Word Family:**
- Serve (v.), Service (n.)

**Synonyms:** Host, Mainframe (máy chủ trung tâm cỡ lớn, thường dùng trong hệ thống doanh nghiệp truyền thống, quy mô lớn hơn "server" thông thường), Backend system (thuật ngữ rộng hơn, chỉ toàn bộ hệ thống xử lý phía sau, không chỉ riêng phần cứng máy chủ), Node (trong hệ thống phân tán, một "node" có thể đóng vai trò server)
**Antonyms:** Client

## 💡 Ghi chú sử dụng (Usage Notes)
- **Register:** Neutral/Technical
- **So sánh:** Server vs Client: "Server" là máy/chương trình cung cấp tài nguyên hoặc dịch vụ, còn "client" là máy/chương trình yêu cầu và sử dụng dịch vụ đó (mô hình client-server); ngoài ra "server" còn có nghĩa khác là "người phục vụ bàn" trong nhà hàng, dễ gây nhầm lẫn ngữ cảnh.
- **Lỗi thường gặp:** Người học hay dùng "server" để chỉ chung chung "internet" hoặc "mạng" (ví dụ "the server is slow" khi ý muốn nói cả đường truyền internet), trong khi thực chất "server" chỉ là một máy tính/dịch vụ cụ thể trong hệ thống.
- **✅ Correct:** The website is down because the server is not responding.
- **❌ Incorrect:** My server is very slow today, I can't load any website. (khi ý thực sự là "internet connection")
