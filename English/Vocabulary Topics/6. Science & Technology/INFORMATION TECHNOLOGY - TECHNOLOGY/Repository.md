# Repository
*noun*
> /rɪˈpɒz.ɪ.tər.i/

---
**Level:** C1 | **Ngữ cảnh:** Technical/Formal | **Chủ đề:** INFORMATION TECHNOLOGY - TECHNOLOGY

## 📌 Ý nghĩa (Meaning)
- **[EN]:** A place where things are stored and can be found, especially software code.
- **[VN]:** Kho chứa, kho lưu trữ.

## 🧠 Mẹo nhớ (Mnemonics)
💡 Repository - 're' (lại) 'po' (bỏ) -> chỗ bỏ đồ lại (kho).

## 🧩 Cụm từ thường đi kèm (Collocations)
- `code repository`: kho chứa mã nguồn
- `central repository`: kho lưu trữ trung tâm
- `clone a repository`: sao chép (clone) một kho mã nguồn
- `push to a repository`: đẩy code lên kho lưu trữ
- `private repository`: kho lưu trữ riêng tư

## 🎬 Ví dụ thực tế (Real-world Examples)
1. 💬 *Daily:* I uploaded my coding homework to a public repository.
   *-> Tôi đã tải bài tập lập trình của mình lên một kho lưu trữ công khai.*
2. 💼 *Work/Academic:* GitHub is widely used as a code repository for open-source projects.
   *-> GitHub được sử dụng rộng rãi như một kho chứa mã nguồn cho các dự án mã nguồn mở.*
3. 🎬 *Media/Movie:* They hacked the main repository and stole the blueprints.
   *-> Chúng đã hack vào kho lưu trữ chính và đánh cắp bản thiết kế.*
4. 📰 *News:* The company accidentally left its internal repository publicly accessible for weeks.
   *-> Công ty vô tình để lộ kho lưu trữ nội bộ ở chế độ công khai suốt nhiều tuần.*
5. 🎓 *Academic:* Researchers maintain a shared repository of datasets for machine learning experiments.
   *-> Các nhà nghiên cứu duy trì một kho dữ liệu dùng chung cho các thí nghiệm học máy.*

## 💡 Ghi chú sử dụng (Usage Notes)
- **Register:** Formal/Technical (nhưng "repo" là cách nói informal rất phổ biến)
- **So sánh:** Repository vs Database: "Repository" thường chỉ nơi lưu trữ mã nguồn, tài liệu hoặc các phiên bản có kiểm soát (version control), còn "database" là hệ thống lưu trữ dữ liệu có cấu trúc để truy vấn, không nhất thiết liên quan đến code.
- **Lỗi thường gặp:** Người học hay viết sai chính tả thành "repositery" hoặc dùng nhầm với "repertory" (kho vở kịch/tiết mục), hai từ phát âm gần giống nhau nhưng nghĩa hoàn toàn khác.
- **✅ Correct:** Please clone the repository before making any changes.
- **❌ Incorrect:** Please clone the repertory before making any changes.
