# Server
*noun*
> /ˈsɜː.vər/

---
**Level:** B1 | **Ngữ cảnh:** Academic | **Chủ đề:** INTERNET

## 📌 Ý nghĩa (Meaning)
- **[EN]:** A computer or program that provides data, services, or resources to other computers (clients) over a network.
- **[VN]:** Máy chủ

## 🧠 Mẹo nhớ (Mnemonics)
💡 Server = serve (phục vụ) + -r → cái máy chủ 'phục vụ' dữ liệu cho các máy khác.

## 🧩 Cụm từ thường đi kèm (Collocations)
- `web server`: máy chủ web
- `server crash`: máy chủ bị sập
- `connect to a server`: kết nối với máy chủ

## 🎬 Ví dụ thực tế (Real-world Examples)
1. 💬 *Daily:* The server was down for an hour, and no one could access the website.
   *-> Máy chủ bị sập trong một giờ và không ai có thể truy cập trang web.*
2. 💼 *Work/Academic:* The research data is stored on a dedicated server with regular backups.
   *-> Dữ liệu nghiên cứu được lưu trữ trên máy chủ chuyên dụng với các bản sao lưu thường xuyên.*
3. 🎬 *Media/Movie:* In *Mr. Robot*, Elliot plans to destroy the main server farm of a global corporation.
   *-> Trong *Mr. Robot*, Elliot lên kế hoạch phá hủy trung tâm máy chủ chính của một tập đoàn toàn cầu.*

## 🕸️ Mạng lưới từ (Word Network)
**Word Family:**
- server (n), serve (v), client-server (adj)

**Synonyms:** host, mainframe, back-end system
**Antonyms:** client
