# Browser
*noun*
> /ˈbraʊ.zər/

---
**Level:** A2 | **Ngữ cảnh:** Daily | **Chủ đề:** INTERNET

## 📌 Ý nghĩa (Meaning)
- **[EN]:** A software application used to access and navigate the Internet.
- **[VN]:** Trình duyệt web

## 🧠 Mẹo nhớ (Mnemonics)
💡 Browse (duyệt) + -r → công cụ để duyệt qua các trang web trên mạng.

## 🧩 Cụm từ thường đi kèm (Collocations)
- `open a browser`: mở trình duyệt
- `browser history`: lịch sử trình duyệt
- `web browser`: trình duyệt web

## 🎬 Ví dụ thực tế (Real-world Examples)
1. 💬 *Daily:* She uses Chrome as her main browser.
   *-> Cô ấy dùng Chrome làm trình duyệt chính.*
2. 💼 *Work/Academic:* The web application is compatible with all modern browsers.
   *-> Ứng dụng web tương thích với tất cả các trình duyệt hiện đại.*
3. 🎬 *Media/Movie:* In *Silicon Valley*, the engineers constantly argue about browser compatibility.
   *-> Trong *Silicon Valley*, các kỹ sư liên tục tranh luận về khả năng tương thích trình duyệt.*
